## 6. Development phases

| Phase | Goal | Exit criteria |
|-------|------|---------------|
| **P0 — Scaffold** | Nextflow DSL2 skeleton, container plan, params schema, CI lint. | `nextflow run main.nf -profile test` completes a no-op end-to-end. |
| **P1 — Read prep + recruit + coverage gate** | Stages 1–6 wired with real test data. | Recruitment yield verified on plant test data at skim depth; coverage gate correctly subsamples an over-covered sample, passes a between-floors sample as `low_coverage`, and soft-fails a sample below the hard floor as `fail` — all without blocking sibling samples ([§2.1.3](02-stages.md#213-decision-matrix)). |
| **P2 — Assemble + viz** | Stages 7 + 9 (stage 8 MEDAKA deferred — see §7 Q6; Flye's built-in polish is the P2 baseline). | Plant chloroplast assembled and visualised end-to-end. |
| **P3 — Bin + validate + extract** | Stages 10, 11, 12, 13. | Barcode FASTA produced for plant + animal clean datasets; ORF validation passes. Note stage 12 (`MINIPROT_CDS`) lands here rather than in P4a: the broad miniprot pass that yields the CDS annotation is the same pass that yields the barcodes (§8 item 3), so extraction cannot be built without it. |
| **P4a — Annotate (`animal_mt` MVP) + collate + report** | Stage 13a for the `animal_mt` arm, plus stages 14, 15, 16; full output bundle, per-sample `report.html`, run-level `run-report.html`. | Taxodactyl handoff bundle validates against schema; **`animal_mt` produces a complete annotation** (CDS from the broad miniprot pass, tRNA/rRNA from MITOS2); plant arms produce a CDS-only annotation explicitly marked `ok_cds_only`; both report tiers render on multi-sample test invocation, including a mixed batch with one soft-failed sample. |
| **P4b — Plant annotation arms** | Decide and implement the `plant_pt` and `plant_mt` annotation strategies. | §9 item 12's benchmark run for both plant arms and a strategy recorded per arm in [§3.1](03-organelles.md#31-what-differs-between-assembly-targets)/[§3.2](03-organelles.md#32-per-stage-parameter-selection); §8 item 3 closed. A recorded decision to ship CDS-only for an arm satisfies this phase. **The `plant_mt` fixture gate is relieved, not closed:** under the two-floor gate ([§2.1.3](02-stages.md#213-decision-matrix)) the existing fixture clears the 10× hard floor and does exercise stages 7–16, so the arm is no longer blocked from being *built*. It remains too shallow to *benchmark* on — §9 item 12's comparison needs a fixture that clears the 30× warn floor ([§5](05-test-data.md)). |
| **P5 — Contamination tolerance** | Minor-contamination datasets. | Acceptance criteria in §5 met. |
| **P6 — Negative-result clarity** | No-assembly and no-locus paths explicit in outputs. | Degraded-sample test yields explicit no-recovery diagnostic, distinct from null output ([brief.md §3.8](brief.md)). |
